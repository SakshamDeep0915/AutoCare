# AutoCare AI — Carbon Black + Orange Theme

This version applies a global Carbon Black + Orange design system across the existing frontend pages without changing API/service logic.

## Run

```bash
npm install
npm run dev
```

Theme palette:
- Background: #080808
- Cards: #151515
- Orange: #F97316
- Orange hover: #FB923C
- Main text: #F4F4F5
- Secondary text: #A1A1AA
- Borders: #292929

`node_modules` is intentionally excluded from the archive.
